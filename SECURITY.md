# Security policy

## Supported versions

| version | supported |
|---|---|
| 1.0.x | yes |
| < 1.0 | no |

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue:

- through GitHub's **Report a vulnerability** button on the repository's
  [Security tab](https://github.com/nickFurlotte/pylmm/security) (a private security advisory), or
- by email to nick.furlotte@gmail.com.

Include the pylmm version, how to reproduce the problem and its impact. Confirmed issues are fixed in a
1.0.x patch release.
